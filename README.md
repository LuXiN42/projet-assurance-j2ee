# Application de gestion d'assurances (J2EE)

Projet universitaire 2026-2027 : application Web de gestion d'une compagnie d'assurance
avec trois profils (**Client**, **Agent**, **Administrateur**).

---

## Prérequis

| Outil | Version |
|---|---|
| JDK | `<17>` |
| Maven | 3.8 ou plus |
| Apache Tomcat | `<10.1>` (Jakarta EE) |
| MySQL / MariaDB | `<8.x>` |
| IDE conseillé | IntelliJ IDEA (licence étudiante = Ultimate gratuite) |
| Git | dernière version |

Vérifier les installations :
```bash
java -version
mvn -version
git --version
```
